# 最后一轮语言与表达复核

Language pass 只能在事实、作者归属、研究状态、问题—方法关系和结构基本稳定后运行。它提升清晰度，不把申请人改写成模型平均声，也不证明 AI 政策允许代写。

## 保留什么

- 保留领域术语、研究状态、限定词和申请人确实做过的动作。
- `suggests`、`in this sample`、`did not detect` 等证据支持的 hedging 不得被润色成确定结论。
- `robust regression` 等技术术语按语境保留；不因某个词看起来“像 AI”就删除。
- 中英文转换先保留论证和事实，再处理句法；允许提交中文时，不强行套英文申请腔。

## 优先处理什么

1. 一句只保留一个主要动作或论证；关系太长就拆句。
2. 用有限动词说明行动：`measured`、`coded`、`compared`、`interviewed`、`traced`、`failed to replicate`，但不把协助升级为主持。
3. 检查数字、单位、日期、缩写首次展开、术语前后一致和作者归属。
4. 删除不提供信息的 prestige 句、空泛 passion 句和重复结尾；把空间留给问题、选择、证据和限制。
5. 检查每个因果词、比较级和创新词是否有相应证据；必要时返回原句与安全改写供用户确认。

## 不做什么

- 不用固定禁词表决定成败；`novel`、`significant`、`robust` 可能是有依据的学术术语。
- 不添加“passionate”“renowned”“holistic”“cutting-edge”等没有事实支撑的声望词，也不把它们机械替换成另一组同义词。
- 不加入俚语、故意错字、碎片句、虚构小故事或“绕过检测”的话术。
- 不把“polished”写成“ready”。如果只改了冠词、节奏和拼写，要明确说这是语言层变化。

## 复核问题

- 这次改写是否改变了个人贡献、研究状态、因果强度或确定性？
- 删除工具名后，读者仍能理解要回答什么问题吗？
- 一个面试追问能否暴露团队成果、未完成结果或不熟悉的术语？
- 目标项目的语言、字符数和格式是否已经按当前来源复核？
