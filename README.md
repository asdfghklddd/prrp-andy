# PRRP_Andy

版本 2.0｜研究核查日期 2026-10-04。

这是一个先分流、采集信息和核对要求，再做研究叙事、严格审计、red-team 和最后语言复核的可复用技能。它不保存申请人的真实隐私，也不把他人案例当填空素材。目标是让 PRE/PR 与 RP 各自完成自己的任务，材料有据、问题清楚、方法可信、表达自然。

## 开始使用

在支持本技能包的环境中选择 `PRRP_Andy`，或让 Agent 读取 `SKILL.md` 及其按需引用文件。技术调用名为 `$prrp-andy`，界面显示名为 `PRRP_Andy`。可以这样发起：

> 使用 PRRP_Andy。先阅读我提供的 CV、项目材料和学校原题，按信息采集流程找出缺口，暂时不要起草。先核对目标项目的 AI 政策；确认允许协作起草后，再分别规划 PRE 与 RP。没有证据的经历、结果和文献不要补造。

也支持：“只批改这份 RP，先检查研究问题和方法是否对应，再做 red-team 和语言 pass，批评后列出我需要补充的事实。”

## 包含什么

核心 SKILL、意图/文种/项目/领域路由、五种工作流、分轮问卷、双路线写作手册、学科适配、严格审稿、red-team、语言 pass、8 个来源清楚的案例、原始来源清单与访问等级、事实表与问题—证据矩阵、可配置机械审查脚本、行为测试及三页只读 DOCX 排版母版。

`assets/reference.docx`是结构与版式参考，不是可直接提交的申请书。它包含PRE和RP两种路线；实际只保留所需模块，删除教学提示。学校要求优先，不强制三页或固定章节。

## 可复现检查

在本包目录中执行（Python 3.10+，仅标准库）：

```bash
python scripts/audit_draft.py draft.txt --requirements templates/requirements.example.json --output audit.json
python -m unittest discover -s tests -p "test_*.py" -v
```

先将实际约束写入配置副本。脚本不会自动替你确定学校规则、排除参考文献或验证事实。输出的词数算法与在线系统可能不同，最终须粘贴检查。测试只是机械功能测试；行为场景是待实际Agent验收的清单，不宣称经过多模型评测。

## 调研与命名边界

小红书未获得可核验笔记正文；知乎、B站部分资料仅索引摘要；已明确降级或排除，不能宣称完成全平台普查。核心方法来自学校要求、大学写作指南与带批注公开样本。来源保留原链接，无整份转载第三方文书。

“Human Lyer”没有确认唯一仓库；采用了Human Writing与Humanizer的适合学术写作部分，并剔除刻意口语化、机械禁词和检测规避主张。对应库和筛选理由见参考文件。

当前包由研究与编辑规则构成，不承诺录取、不保证任何 AI 检测结果、不自动向学校提交，也不代表已经安装或同步到其他桌面 Agent。项目要求和 AI 政策以当季官方页面与申请系统为准；本包中的示例、旧快照和外部评论只能帮助定位检查项。
